## Hoja de ruta tras el curso

1. **Construye 3 proyectos propios** de complejidad creciente (ver ideas en el proyecto final). Es lo que más enseña.
2. **Profundiza en un framework**: Next.js o React Router (modo framework).
3. **Domina TypeScript** si aún no lo usas: es casi estándar en el trabajo profesional.
4. **Datos**: TanStack Query y una API real (REST/GraphQL) con autenticación.
5. **Calidad**: pruebas (Vitest + Testing Library), accesibilidad y rendimiento (Lighthouse/Profiler).
6. **Producción**: CI/CD, despliegue, monitorización (Sentry), analítica.
7. **Lee código ajeno**: repositorios de proyectos open source y librerías de componentes.

## Hábitos que funcionan

- **Escribe código todos los días**, aunque sean 30 minutos.
- **Rompe cosas** a propósito y lee los errores con calma (hay una guía de errores en este curso).
- **Explica** lo que aprendes (a alguien o por escrito): revela lo que no entiendes.
- **Lee la documentación oficial**: es excelente y está en continua mejora.
- **Revisa tu propio código** días después y refactoriza.
- Contribuye con un *issue* o *pull request* pequeño en un proyecto abierto.

## Cómo elegir tu stack (resumen)

| Si quieres… | Combina |
|---|---|
| Aprender y hacer SPAs | Vite + React + React Router + TanStack Query |
| Sitio con SEO y datos en servidor | Next.js (App Router) + TypeScript |
| App empresarial grande | TypeScript + Redux Toolkit/RTK Query + Testing Library + Storybook |
| Interfaz muy cuidada con rapidez | Tailwind + shadcn/ui (Radix) |
| Móvil | React Native / Expo |

## Antes de despedirnos

Has recorrido desde **"¿qué es un componente?"** hasta **Server Components, concurrencia y arquitectura**. No hace falta recordarlo todo: lo importante es entender los **modelos mentales** (pureza, estado como instantánea, flujo unidireccional, efectos como sincronización, composición) y saber **dónde buscar** el resto.

🎓 **Siguiente acción recomendada**: vuelve al **Playground**, abre una carpeta nueva en tu editor y crea la primera versión de un proyecto que te emocione. ¡Mucho éxito!
